# 问事智能体开发中心：知识管理

本次在现有 Eino Harness 管理平台中保留三个工作区：知识与能力、智能体开发、调试与发布。知识库不是计算引擎的替代品：排盘、五格、飞星等结果仍以已配置工具返回值为准。

## 工作流

1. 在知识与能力 → 知识库中新建或选择专题库，上传文档或添加文本，填写版本、作者、出处和使用许可。
2. 等待解析，预览原文分块；核对内容后审核启用。新资料默认不参与检索。
3. 使用检索验证检查实际命中。智能体开发中绑定知识库，保存草稿，通过评测后发布。
4. Wiki 与关系图页展示引擎实际状态、条目、来源引用、版本号、队列与孤立条目数量。Wiki 生成需要单独的 KnowledgeQA 模型和每库 Wiki 索引配置；配置不足会显示未启用，不填充演示数据。每库 Wiki 设置可选择已配置的 KnowledgeQA 模型并启停；新上传或重解析的文档触发生成，已有文档不会因开关改变就立即全部生成。
5. Wiki 图谱中的边代表条目链接；Neo4j 实体抽取是独立能力。本次不安装 Neo4j，不声称具备实体推理能力。

## 权限与运行边界

仅 platform_super 管理员可访问适配接口，且知识库必须已在问玄登记。接口枚举固定读取操作，不允许透传任意 WeKnora 地址或接口。模型密钥、存储配置、租户标识不返回浏览器。Wiki 正文按纯文本显示，避免外部资料中的 HTML 执行。

Wiki 当前用于运营浏览和审校；不会绕过原有文档审核、绑定范围与撤销检查进入 Harness。Wiki 条目当前不支持管理台编辑、回滚及人工审批发布，后续应扩展独立的生成内容治理流程后再用于回答。
