# 心愿与 DIY 创作收益

## 固定七个入口
求平安、求财运、求姻缘、求事业、求学业、化太岁、做法事不增删。
管理台 → 增长运营 → 心愿与服务关联：分别编辑每个提供者的具体服务。初始化师傅关联采用当前寺院已有的同编码服务关联；上线后需运营按实际服务能力逐项复核，关联不代表资质或效果认证。

## 广场与收益
保存作品 → 我的设计 → 作品详情 → 发布到广场。材料缺货或下架时不能发布；编辑公开作品后需要重新发布。
采用原作品或服务器创建的副本下单，收益归最初作者，最多追溯32层；自购不计奖。不按相似度猜测作者，不支持多级分佣。复制后的修改仍保留来源归属。
新订单规则：材料实付5%，单笔最高20元，订单完成7天后自动结算。只对上线后形成规则快照的订单生效；不追补历史收益。模拟支付和测试余额不产生现金或权益奖励。

## 钱包与提现
我的 → 钱包 → 创作收益。与消费余额分账，有待结算、可提现、提现中、累计已打款和明细。
最低提现1元，人民币人工银行转账，平台手续费0元。管理员在 DIY与加持服务 → 创作奖励与提现审核申请，然后进入打款状态。实际完成银行转账、核对后，填写银行唯一流水及对账说明，才登记已打款。接口不自动向银行转账，结果未知时保持处理中。失败必须核实未付款后才能释放冻结。收款银行卡号AES-GCM加密落库，用户侧显示尾号；收款人身份仍需人工核验。

## 退款与运营
任意成功退款会撤销整笔奖励；处理中退款暂停结算。现金已经提走的退款形成待抵扣欠额并阻止继续提现；消费余额先扣可用余额，不足部分记为创作账户待抵扣。已用奖励券的退款写入人工核对审计，不伪造券已撤销。
奖励规则可切换现金、消费余额、优惠券，按订单快照执行。优惠券按有效模板逐单生成独立券并扣模板库存。缺券或服务故障保留待结算并每5分钟重试。人工结算重试遵守相同期限和幂等规则。

## 发布/恢复
SQL先备份后执行新增迁移20261013_wishes_creator_rewards.sql，确认授权，再更新CI数据库合同基线；发布diy/product、管理台、H5。原余额和历史收益表不做回填或删除。旧版本回滚前需先关闭新增奖励并处理未结算记录；不要删除新账本。银行卡加密使用持久化AuthSecret派生的版本化密钥，更换该密钥前必须迁移重加密，不能直接轮换。
测试/部署结果以本目录日志及最终发布清单为准。
