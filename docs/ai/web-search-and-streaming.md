# 问事联网搜索与增量回答

## 配置入口

平台超级管理员进入「AI 问事 → 模型连接设置 → 联网搜索」。

1. 主用服务选择博查、腾讯云、Tavily 或 Brave，填写该服务 API Key。
2. 如需故障备用，选择另一服务并填写独立密钥。更换服务时不会沿用其他服务密钥。
3. 分别点击「测试搜索连接」「测试备用连接」。每次只测试指定服务，以固定公共检索词验证；可能消费供应商额度，测试成功不代表已保存或开放给用户。
4. 设置时间范围、每次来源数（1–10）、每轮搜索次数（1–4）、只保留/排除站点（各最多 10 个域名）。语言、地区偏好仅用于 Brave，其余服务按查询词检索。站点规则对最终结果强制生效，供应商不支持的组合使用本地结果过滤，来源数可能减少。
5. 可开启「按需读取来源正文」。仅可读取本轮搜索实际返回的 URL，最多两页；网页读取与搜索共用 Harness 的工具调用预算。
6. 保存并生效。在智能体已发布版本中允许联网；用户还需要打开当轮「联网搜索」开关。

主服务设为停用会关闭整条搜索链路，即使备用密钥存在也不会自动启用。旧配置无需迁移：未提供的新字段保留现有设置，新能力默认不自动开启。密钥保存在既有加密设置文件，公共 API 只返回是否配置；更换/清除密钥、搜索偏好均进入版本审计。

## 引擎和接口

| provider | 接口 | 鉴权 |
|---|---|---|
| bocha | `POST https://api.bochaai.com/v1/web-search` | Bearer API Key |
| tencent | `POST https://api.wsa.cloud.tencent.com/SearchPro` | WSA **服务 API Key**，不是 SecretId/SecretKey |
| tavily | `POST https://api.tavily.com/search` | Bearer API Key |
| brave | `GET https://api.search.brave.com/res/v1/web/search` | X-Subscription-Token |

腾讯使用服务 API Key 版的 `FromTime` / `ToTime` 时间参数，不能套用腾讯云标准签名 API 的不同参数版本。为兼容不同套餐，不发送仅部分套餐支持的 `Cnt`；最多来源数在平台内再次截断。`Site` 仅在配置一个允许域名时传入，多域名及排除规则仍在平台内校验。

## Harness 调度与预算

每次运行创建独立搜索会话，不跨用户或跨轮次共享已发现的链接及次数计数。

`用户本轮开启 + 已发布智能体允许 + 主服务配置就绪 → search_web(query) → 必要时 read_webpage(url) → 综合已有知识和网页证据 → 引用真实链接回答`

- 主服务成功（包括空结果）直接返回，不额外搜索备用服务。连接、HTTP、供应商业务错误或格式异常可使用备用一次。取消及无效输入不触发备用。每次最多两次搜索 API 请求，总调用受每轮搜索限制及既有 Harness 工具预算双重约束。
- 单供应商超时 15 秒；主备合计上限 25 秒；JSON 响应上限 1 MiB。结果记录实际 provider、fallbackFrom（如有）、检索时间、来源标题、URL、摘要与供应商发布日期，并沿现有工具执行记录展示。这里是次数预算，不是基于供应商价格计算的账户金额限额。
- 网页读取不携带搜索密钥、用户 Cookie 或登录身份。仅允许 HTTP(S) 的 80/443 端口；DNS 解析结果全部验证，连接到验证后的 IP，禁用代理和重定向，拒绝内网、元数据及保留网段。最多读取 2 MiB，仅支持 HTML/纯文本，抽取并保留最多 12000 字，标记截断；不执行网页 JS，不解析 PDF 或需要登录的页面。
- 正文与摘要都是外部不可信证据，不执行其中指令，不自动导入 WeKnora、Wiki、图谱或长期记忆。
- 引擎按管理员主备配置调用；本版不自动按语言选择另一主引擎，也未接入百度、豆包或百炼。

## 流式回答修复

原路径已经使用模型流式响应和客户端 SSE，但 `einopoc.Harness.consume` 在模型流 EOF 后才执行正文回调，导致前端等待整条回答。

现在在收到正文片段后，对累计内容执行输出校验，然后以**完整快照**回调。若后续出现工具调用，会清除此前的临时前言，随后显示正式回答。失败会尝试清空临时快照，失败/取消状态仍由原任务状态机处理。推理内容和工具参数不会作为正文输出。

实时会话持久化合并为约 120 ms 一次，已有 SSE 接口约 180 ms 检测更新并立即 flush，最终完成状态写入完整答案；H5 与 iOS 都已消费 snapshot，后端部署后可共同受益。该机制是后端持续输出，不是前端把完整回答做打字机动画。模型思考/工具检索阶段仍可能暂时没有正文。

## 验证及上线边界

本次新增无外部密钥的协议测试，覆盖中文引擎请求/响应、供应商 HTTP 200 业务错误、主备凭据隔离、空结果与取消不回退、配置加密/重启/旧客户端兼容、搜索预算、网页来源限制及正文截断、工具权限，以及上游等待首段正文已发布后才继续输出的真实流式回归。

浏览器界面验证使用本机模拟 API，仅证明表单交互与请求契约；不代表供应商商业账号和真实内容质量验收。上线后需用真实服务 API Key 分别测试主备，验证一次用户开启联网的真实对话及来源记录。不要把密钥放入文档或聊天。
