# 用户问事 Harness（2026-09-29）

> 下文保留初次接入记录，其中 55 秒及首次报告旧流程等描述属于当时快照。当前五个专题补强、预算与发布边界见 [专题工具依据补强](topic-evidence.md)；该补强尚未部署。

本次将 Eino ADK 接入用户文字/图片问事与报告追问。原先用户路径是预先选定技能后的一次工具/模型回答；现在模型可依据工具结果继续选择下一步。后台旧调试接口仍保留作对照，不把调试成功等同于线上验收。

## 能力与用户路径

- 根据目标直接回答，或多步读取关联报告、选择八字/紫微/奇门/塔罗/六爻工具，再综合回答。只暴露启用且受审查的只读工具。
- 所有计算使用当前用户已确认的结构化资料。模型调用工具只能传空对象，不能编造出生时间、替换工具地址或读取任意报告。
- 缺资料暂停本轮，消息携带 `agent.clarification`（字段、条件、已填值）；H5 提供“补充资料并继续”。提交后重建原目标与已确认资料，再运行新一轮。
- 报告追问每轮复核当前会话、报告所有者及解锁状态。原报告经 `read_report` 按需读取，不当作新计算的事实输入。
- 对话和结构化资料持久保存在已有消息表；刷新与服务重启后可继续补充。用户运行通过重建上下文继续，不是将运行中的模型请求原地续传。后台调试继续使用既有加密检查点。
- H5 展示实际处理阶段和可展开的工具调用记录。展示工具状态，不展示隐藏推理过程。
- 工具失败给模型返回脱敏观察结果，允许其在预算内重试；同一任务的成功计算缓存，避免重复抽取改变结果。
- 每轮最多 4 次模型调用、4 次工具调用、55 秒。无答案且 finish_reason=length 时，仅对支持 thinking 参数的兼容提供方允许一次关闭思考重试，仍计入原预算。截断的部分回答不会作为完成结果发布。
- 汇总每轮调用及失败尝试的 Token/推理 Token/费用。上游不提供 usage 的情况不能推算出精确费用；费用仍使用既有配置单价。

## 运营与发布

`AI_HARNESS_ENABLED=true` 默认启用新执行引擎；设为 `false` 并重建服务可回退旧执行路径。当前仅支持已配置的 OpenAI-compatible 提供方，需确认模型支持工具调用。

`AI_AGENT_OPERATIONS_ENABLED` 是另一个开关，控制经过评测的版本配置是否对用户生效。开启 Harness 不等于自动发布管理台草稿。服务启动时固定引擎模式，模型连接仍按每次请求的不可变快照读取。

管理台显示实际引擎。Harness 下的质量评测走同一执行器，校验类型错误会在调用前拒绝；缺少必要资料属于补问，不能当作“无效资料已拒绝”的成功用例。普通问答引擎的旧评测不能用于 Harness 发布、扩大覆盖或激活旧版本。切换引擎前应重新评测并准备匹配版本，或显式恢复原始配置。

依赖已有迁移 `scripts/db/20260928_ai_agent_operations.sql`、`scripts/db/20260928_ai_agent_runtime.sql`。本次没有新增业务表，澄清元数据复用助手消息 `input_json._agent`，API 返回独立 `agent` 字段。先备份并执行此前尚未执行的迁移，再部署 AI 服务、H5、管理台。

## 本地验证与范围

在 `services/infrastructure/ai-service` 运行 `GOTOOLCHAIN=go1.23.0 go test -race ./...`。测试覆盖真实 Eino 循环与本地 HTTP 模型适配：读报告后计算、缺资料中断及下一轮继续、工具失败重试、禁止模型编造参数/调用未授权工具、重复计算缓存、预算终止、思考额度耗尽恢复及计量、上下文重建和引擎评测门槛。

H5/管理台执行各自 `npm run build`。Ego Lite 使用合成接口数据验证 393px 下的补问表单、继续、调用记录与无横向溢出；这不等于真实手机 Safari 或生产模型验收。未设置独立测试 MySQL DSN 时，数据库完整发布生命周期测试按原规则跳过，SQL 契约由 sqlmock 验证。

本次没有部署生产或重放生产个人报告。正式发布后仍须用受控测试账号验证实际模型工具调用、MCP、报告追问和 SSE。原生 iOS 本次未改动，新的结构化补问弹窗和工具详情为 H5 交付。

当前不包含任意网页检索、知识库、跨会话长期记忆、多智能体、付款/下单等写操作，也不宣称具备工具本身未实现的大运/流年计算。专题报告的首次生成仍使用原报告流程，报告追问使用 Harness。
