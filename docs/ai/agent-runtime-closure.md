# 智能体运营闭环（第二阶段）

2026-09-28，本地实现；需新增迁移后部署。入口：平台管理台 → AI 问事 → 智能体运营管理，仅平台超级管理员可操作。

## 新增能力与操作

1. **质量评测**：每个启用技能至少一条正常回答用例，可再添加无效资料拦截用例。配置问题、合成资料、最低输出字数、必含/禁含词，保存后运行。全部通过且草稿、模型连接修订号均未变化，结果 24 小时内才可发布。单次调试成功不再作为发布依据。
2. **候选与稳定版本**：发布初始覆盖 0%；服务端开关开启后可按 10%、25%、50%、100% 逐步扩大，比例按账号固定分桶，跨设备一致。未命中账号使用稳定版本。上一候选达到 100% 后，下次发布将其转为稳定版本。配置存储故障明确返回失败，不静默绕过策略。
3. **生效范围**：发布的技能启停、工具绑定和提示词接入技能目录、文字对话和专题报告的新建/重试。请求与其后台工作持有固定配置；下一轮请求可使用新版本。报告保留原 6000 Token 上限，对话上限不套用到长报告。
4. **持久恢复**：Eino 调试的待补充任务加密保存 24 小时，可在服务重启后从运行记录继续。跨实例同时恢复只允许一个领取，已消耗的调用预算、已确认资料和计算时间继续保留。
5. **回滚与审计**：可立即恢复历史版本或原始配置；比例调整、保存、发布和回滚均记录操作人及说明。扩大覆盖时若模型连接配置变化，必须重新评测和发布。

## 边界

- 2026-09-29 更新：用户文字/图片问事及报告追问已接入 Eino Harness；详见 [用户问事 Harness](live-harness.md)。专题报告首次生成仍沿用原流程。
- 自动评测是确定性断言，不是另一个模型评分，更不等于专业准确性认证；仍需人工抽检真实回答。
- 每组最多 20 条、总时限 3 分钟、每条最多 50 秒，同一时间全局一组评测。无效资料用例必须在模型和工具调用前被输入检查拒绝，上游超时不算通过。
- 正在外部调用时进程退出，不自动重放。恢复租约 70 秒后显示失效；模型连接修订变化也会拒绝恢复，要求重新开始。
- 未配置加密密钥时保留原 10 分钟进程内恢复，并在界面明确说明。进程内最多 8 个任务；单实例每位管理员一个活动任务，跨实例对同一检查点采用数据库租约，不承诺全局按管理员限额。
- 暂无知识库与来源引用、长期记忆、可视化编排、多智能体协作。用户 Harness 已汇总上游返回的 usage 与配置单价费用；后台旧调试记录不提供同等计量。

## 数据和权限

先执行 `scripts/db/20260928_ai_agent_operations.sql`，再执行 `scripts/db/20260928_ai_agent_runtime.sql`。新表：`ai_agent_checkpoint`、`ai_agent_evaluation`、`ai_agent_rollout`。不修改现有用户资金或业务订单。

检查点使用 AES-GCM，以任务 ID 作为附加认证数据；从已有 `AI_SETTINGS_ENCRYPTION_KEY` 派生独立用途密钥，不保存模型 API Key。检查点包含问题、输入和工具状态，完成或取消后删除；过期密文、30 天前评测与调试记录在新调试启动时分批清理（每类最多 1000 条）。没有独立定时清理任务，数据库备份遵循原备份保留规则。

**评测资料作为配置明文保存，只使用合成资料。** 调试结果可能复述输入；用户运行列表继续隐藏原始问题、出生资料和工具正文。所有管理接口沿用可信网关身份与平台超级管理员校验，不把 AI 服务端口直接暴露公网。

新增接口前缀 `/api/v1/ai/admin/agent`：

| 接口 | 用途 |
| --- | --- |
| POST /rollout | 修订号校验后更新覆盖比例及审计 |
| POST /evaluations | 启动当前草稿整组评测 |
| GET /evaluations | 最近 30 组评测 |
| GET /evaluations/:id | 用例结果与失败原因 |

## 部署与验证

1. 备份 AI 数据库，依次执行迁移，再部署 AI 服务与管理台。原服务开关默认关闭，新增比例为 0，不自动接管用户请求。
2. 配置已有模型加密密钥；完成真实模型和 MCP 的合成资料测试。
3. 保存、评测、发布候选版本。开启实际容器环境中的 `AI_AGENT_OPERATIONS_ENABLED=true` 并重建 AI 服务，再从 0% 逐步放量。缺表时不应开启。
4. 查看对话运行技能版本中的 `@a<版本号>`，检查专题报告创建/重试、用户模型选择和 SSE。每次扩大范围都记录说明。
5. 异常时管理台恢复原始配置，或关闭服务开关并重建容器。

模块内命令：

```sh
GOTOOLCHAIN=go1.23.0 go test -race ./...
GOTOOLCHAIN=go1.23.0 go vet ./...
GOTOOLCHAIN=go1.23.0 CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -o /tmp/askxuan-ai-runtime .
```

MySQL 测试必须设置 `AI_AGENT_OPS_TEST_DSN`，限定回环地址、专用库 `askxuan_agentops_test`。覆盖：未评测/单次调试/失败评测不能发布，评测通过与修订失效、并发发布、0% 隔离与逐步扩大、回滚、两实例抢占检查点、预算延续、密文篡改及跨任务恢复拒绝、完成后密文删除。

前端：`apps/web-platform-admin` 中 `npm run build`。浏览器夹具使用专用 `askxuan_agentops_browser` 库、真实 Eino 和 SQL，但模型及 MCP 响应为合成协议夹具；不能把它视为真实模型或生产验收。
